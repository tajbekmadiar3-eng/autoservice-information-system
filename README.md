# Автосервис ақпараттық жүйесі

Автосервис орталығының негізгі бизнес-процестерін автоматтандыруға арналған ақпараттық жүйе жобасы.

## Мақсаты
Тапсырыс-нарядтарды ашу, жөндеу жұмыстарын жоспарлау және бақылау, қосалқы бөлшектер қорын есепке алу, клиенттермен өзара әрекеттесу және қаржылық-аналитикалық есептерді жүргізу процестерін автоматтандыру.

## Пайдаланушы рөлдері
- Клиент (автокөлік иесі)
- Администратор (қабылдаушы-менеджер)
- Автошебер (механик)
- Басшы (сервис иесі)

## Жүйе компоненттері
1. Пайдаланушы интерфейсі (Frontend)
2. Авторизация және аутентификация модулі
3. Бизнес-процестер модулі
4. Деректер қоры (Database)
5. Іздеу және сүзу модулі
6. Хабарламалар модулі
7. Есеп беру модулі (Analytics & Reporting)
