# Use Case сипаттамасы

## Актерлер
| Актер | Сипаттама |
|-------|-----------|
| Клиент | Онлайн жазылады, жөндеу мәртебесін бақылайды |
| Администратор | Тапсырыс-наряд ашады, жұмыстарды бөледі, төлемді тіркейді |
| Автошебер | Диагностика мен жөндеуді орындайды, мәртебені жаңартады |
| Басшы | Есептер мен KPI-ді қарайды |

## Use Case тізімі
1. Қызметке онлайн жазылу
2. Тапсырыс-наряд ашу
3. Диагностика жасау
4. Қосалқы бөлшектердің бар-жоғын тексеру
5. Жөндеу мәртебесін жаңарту
6. Төлемді тіркеу
7. Аналитикалық есепті қарау

## UC-1: Қызметке онлайн жазылу
- **Актер:** Клиент
- **Алғышарт:** Клиент жүйеге кірген
- **Негізгі сценарий:**
  1. Клиент қызметтер тізімін ашады
  2. Қажетті қызметті таңдайды
  3. Бос уақытты таңдайды
  4. Көлік деректерін енгізеді
  5. Жүйе жазылуды растап, хабарлама жібереді
- **Нәтиже:** Жазылу тіркелді

## UC-2: Жөндеу процесі
- **Актерлер:** Администратор, Автошебер
- **Негізгі сценарий:**
  1. Администратор тапсырыс-наряд ашады
  2. Автошеберге жұмыс тағайындайды
  3. Автошебер диагностика жасайды
  4. Жүйе қойма қорын тексереді
  5. Автошебер жөндеуді орындап, мәртебені «Аяқталды» етеді
  6. Администратор төлемді тіркейді
  7. Клиентке дайындық туралы хабарлама жіберіледі
- **Балама сценарий:** Бөлшек жоқ болса, жүйе автоматты тапсырыс жасап, клиентке хабарлайды
