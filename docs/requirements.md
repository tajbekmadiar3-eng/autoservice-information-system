# Жүйеге қойылатын талаптар

## Функционалдық талаптар
| ID | Талап |
|----|-------|
| FR-1 | Клиент қызметтер тізімі мен бағаларын көре алуы керек |
| FR-2 | Клиент онлайн жазылып, уақытты таңдай алуы керек |
| FR-3 | Администратор тапсырыс-нарядты ашып, жаба алуы керек |
| FR-4 | Жүйе клиент пен автокөлік деректерін (VIN, мемлекеттік номер, модель) сақтауы керек |
| FR-5 | Автошебер тапсырыс мәртебесін жаңарта алуы керек («Басталды», «Күтілуде», «Аяқталды») |
| FR-6 | Жүйе қосалқы бөлшектер қалдығын есепке алып, жөндеу кезінде автоматты шегеруі керек |
| FR-7 | Жүйе бөлшек таусылғанда және тапсырыс мерзімі өткенде ескерту жіберуі керек |
| FR-8 | Клиент жөндеу мәртебесін нақты уақытта көре алуы керек |
| FR-9 | Жүйе SMS/Email/Telegram арқылы хабарлама жіберуі керек |
| FR-10 | Басшы кіріс пен KPI бойынша есептерді көре алуы керек |

## Функционалдық емес талаптар
| ID | Талап |
|----|-------|
| NFR-1 | Қауіпсіздік: рөлдік қол жеткізуді бақылау, парольдерді шифрлап сақтау |
| NFR-2 | Жылдамдық: бет жүктелуі 3 секундтан аспауы керек |
| NFR-3 | Сенімділік: деректердің резервтік көшірмесі күн сайын жасалуы керек |
| NFR-4 | Қолайлылық: интерфейс веб және мобильді құрылғыда жұмыс істеуі керек |
| NFR-5 | Масштабталу: жүйе бірнеше филиалды қолдай алуы керек |
